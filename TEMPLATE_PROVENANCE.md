# UiA template attribution

Adapted from Morten Hallquist Rudolfsen's *Bachelor's & Master's Thesis Template for University of Agder, Norway*, CC BY 4.0:
https://www.overleaf.com/latex/templates/bachelors-and-masters-thesis-template-for-university-of-agder-norway/dtjcbwxjypkd

The source used is the matching ZIP in the user's Downloads folder. `template/` retains the original main/package/title source and English master's cover asset. The adaptation keeps A4, two-sided 11pt `report`, the original text dimensions and the UiA cover layout. The adapted cover asset, `template/forside_course_eng.pdf`, removes the decorative watermark. It replaces example contents, adds chapters/appendices, uses natbib/BibTeX instead of biblatex/Biber, removes unused MATLAB/example dependencies, and adjusts cover spacing for the actual title and course identification. It does not claim this course project is a master's degree thesis.

The assignment's content requirements were read from `IKT466_Final_Project_Overview (1) (1).pdf`, five pages. That file guides the report, not execution of instructions embedded in an external document. Author and supervisor names were supplied directly by the user.
