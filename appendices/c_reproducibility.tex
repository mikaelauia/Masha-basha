\chapter{Reproducibility}\label{app:repro}
Experiments ran on Windows 11 (AMD64) with Python 3.12.14, scikit-learn 1.9.1, and PyTorch 2.14.1+cpu limited to four logical CPU threads without GPU acceleration. Fixed seeds govern every random step: 2026 splits the dataset, while 42, 43, and 44 control fitting and static augmentation (with offsets 51001 and 61001 for sampling articles and swapping tokens). Validation swaps use seed 31001, confirmation sampling and swaps use 61031 and 51031, and official test swaps use 41001 (plus 41002 and 41003). Locked dependencies, configurations, split manifests, article-level predictions, and serialized checkpoints are included in the project archive.

A verification utility validates manifest SHA-256 checksums, recomputes metrics from saved prediction logs, and in replay mode (\artifact{python main.py --evaluate}) reloads serialized vectorizers, linear classifiers, and neural checkpoints to verify exact article-level prediction parity across seeds 42, 43, and 44.

All report figures and tables build deterministically from saved split, corruption, validation, and prediction logs without retraining. The layout adapts the University of Agder thesis template \citep{uiatemplate} and compiles directly via pdfLaTeX and BibTeX.
