\chapter{Reproducibility}\label{app:repro}
Experiments ran on Windows 11 (AMD64) with Python 3.12.14, scikit-learn 1.9.1, and PyTorch 2.14.1+cpu limited to four logical CPU threads without GPU acceleration. Fixed seeds govern all randomness: 2026 for dataset splitting; 42, 43, and 44 for fitting and static augmentation (with offsets 51001 and 61001 for document sampling and token swaps); 31001 for validation swaps; 61031 and 51031 for sampling and corrupting the 4,000-article confirmation split; and 41001 (plus 41002 and 41003) for official test swaps. Locked dependencies, configurations, split manifests, article-level predictions, and serialized checkpoints are included in the project archive.

A verification utility validates manifest SHA-256 checksums, recomputes metrics from saved prediction logs, and in replay mode (\artifact{python main.py --evaluate}) reloads serialized vectorizers, linear classifiers, and neural checkpoints to verify exact article-level prediction parity across seeds 42, 43, and 44.

All report figures and tables build deterministically from saved split, corruption, validation, and prediction logs without retraining. The layout adapts the University of Agder thesis template \citep{uiatemplate} and compiles directly via pdfLaTeX and BibTeX.
