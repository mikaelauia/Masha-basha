\chapter{Reproducibility}\label{app:repro}
All experiments were executed on a Windows 11 workstation (AMD64 architecture) using Python 3.12.14, scikit-learn 1.9.1, and PyTorch 2.14.1+cpu restricted to four logical CPU threads without GPU acceleration. Randomness is controlled via fixed seeds: seed 2026 for the stratified dataset split, seeds 42, 43, and 44 for model fitting and static training augmentation (with derived offsets 51001 and 61001 for stratified document selection and token swaps), seed 31001 for validation spelling swaps, seeds 61031 and 51031 for selecting and corrupting the 4,000-article confirmation sample, and seed 41001 (plus 41002 and 41003 for the extra sensitivity draws) for official test spelling swaps. Locked package versions, configuration records, split manifests, article-level predictions, and serialized checkpoints accompany the full project archive.

A built-in verification utility checks SHA-256 checksums across saved manifests and recomputes summary metrics directly from the stored prediction logs. In replay mode (\texttt{python main.py --evaluate}), it reloads the serialized vectorizers, linear classifiers, and neural checkpoints to confirm that every restored model reproduces its saved article-level predictions across fitting seeds 42, 43, and 44.

All figures and tables in this report are generated deterministically from recorded split definitions, corruption statistics, validation histories, and test prediction logs without retraining. The report layout adapts the University of Agder thesis template \citep{uiatemplate}, and this standalone Overleaf package compiles directly with pdfLaTeX and BibTeX.
