\section{Reproducibility}\label{app:repro}
All experiments ran on a Windows 11 workstation with an AMD Ryzen 3 4300U CPU, using four logical threads. We used Python 3.12.14, scikit-learn 1.9.1, and PyTorch 2.14.1+cpu.

We used seed 2026 to split the filtered AG News pool. Seeds 42, 43, and 44 control fitting and training augmentation, with augmentation offsets 51001 and 61001. Validation swaps use 31001. Confirmation sampling and swaps use 61031 and 51031. Official test swaps use 41001, with extra draws 41002 and 41003. The bootstrap seeds are 92123 and 71102.

The exploratory BGE comparison uses the MIT-licensed \texttt{BAAI/bge-small-en-v1.5} checkpoint at revision \texttt{5c38ec7c} \citep{bgecheckpoint}. We froze the encoder and cached the 384-dimensional CLS vectors without using labels.

Dedicated modules organize the software: \artifact{main.py} handles data, corruption, baseline runs, and verification, \artifact{linear_methods.py} and \artifact{optimized_linear.py} implement TF-IDF, character, SVM, hybrid, and interior-sorted models, \artifact{cnn_methods.py} implements scheduled and subword CNNs, \artifact{pretrained.py} caches frozen embeddings and fits neural heads, and \artifact{optimization_pass.py}, \artifact{analyze_optimization.py}, and \artifact{plot_optimization_learning.py} run confirmation, bootstrap, and plotting passes. Seven test suites in \artifact{tests/} pass all 48 automated checks. In replay mode (\artifact{python main.py --evaluate}), a verification script validates SHA-256 checksums and reloads checkpoints without retraining to confirm exact article-level prediction parity across 192 new and 144 reference prediction sets. Report figures and tables build deterministically atop the University of Agder thesis template \citep{uiatemplate}.
