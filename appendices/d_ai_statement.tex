\chapter{AI assistance and author responsibility}\label{app:ai}
In accordance with the IKT466 course guidelines on artificial intelligence tools, we disclose the AI systems used during this project and how their outputs were verified.

\section{Tools and versions used}
OpenAI Codex (including GPT-6.1 Terra and GPT-6.1 Sol) assisted with project planning, code implementation, debugging, experiment execution, data analysis, plotting, and initial report drafting. Anthropic Claude provided editorial critique during earlier review passes. Google Antigravity powered by Gemini 4 Argon (High) was used to revise the prose across the entire report for natural academic readability, verify alignment against all requirements in the IKT466 project specification, and run a series of review passes.

\section{Verification of generated code and text}
Every architectural description, equation, and hyperparameter setting in the report was checked directly against the implementation. All reported accuracy scores, Macro-F1 values, $F_1$ scores by topic, bootstrap confidence intervals, parameter counts, and training timings were verified against the saved experimental outputs. For example, the Subword CNN confusion matrix with seed 42 (Table~\ref{tab:confusion-review}), the net changes in correct predictions by topic (Table~\ref{tab:topic-correct-change}), and the paired counts of changes in correct predictions (Figure~\ref{fig:paired-changes}) were independently recomputed using the saved predictions for individual articles.
